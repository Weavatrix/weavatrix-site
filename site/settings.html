Appearance

The site follows your operating system by default. Pin a theme if you would rather it stayed put, and it will stay put on this browser until you change it back.

Where this is kept. The choice is written to this browser's local storage under weavatrix-theme. It is not a cookie, it is never sent to a server, and it never leaves this device. Clearing site data returns the site to Auto. With scripting off the site stays dark, which is what it has always been.
